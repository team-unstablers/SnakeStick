# CLAUDE.md

Guidance for coding agents working in this package.

## What this is

WIMLib is a Swift package over [wimlib](https://wimlib.net) that reads WIM files: image metadata, and extraction of paths from an image. It also writes small WIMs for tests. It is part of **SnakeStick** (the repository one directory up), which uses it on a Windows ISO's `sources/boot.wim`. `README.md` describes the API and the design; read it first.

Status: stage 10 is implemented; see `Prompts/10-swift-api.report.md`, which records where the implementation departs from `Prompts/10-swift-api.xml` and why.


## Commands

```sh
swift build
swift test
swift test -c release
git -C Vendor/wimlib status --short        # must print nothing
nm -gU .build/out/Products/Debug/CWIMLib.o # must list only _wimlib_* symbols
```

There are no opt-in integration tests; nothing here touches disks or needs privileges. Wrap long runs in a watchdog (macOS has no `timeout`): run the command in the background and poll it with `kill -0`.

## Submodule rules

- `Vendor/wimlib` stays unmodified: `git -C Vendor/wimlib status --short` must be empty. Workarounds go in `Package.swift` or `Vendor/CWIMLib/`.
- Never run `bootstrap` or `configure` inside `Vendor/wimlib`. To regenerate `config.h`, clone the submodule into a scratch directory, check out the tag, and run the commands in the `Package.swift` header there.
- When moving to another tag: regenerate `config.h`; compare the sources list in `Package.swift` with `libwim_la_SOURCES` in `Makefile.am` (plus the non-Windows `unix_apply.c` and `unix_capture.c`); check `grep -rnw DEBUG src include` is still empty; check the flags in `AM_CFLAGS`/`PLATFORM_CFLAGS`; update the version in the smoke test, `WIMFile.wimlibVersion`'s test, README and this file.

## Things that break quietly

- **Initialization order.** `WIMLibGlobal.initialize()` must run before any other wimlib call in the process. wimlib initializes itself implicitly with default flags otherwise, and path lookups then become case-sensitive with no error. Every public entry point calls it first; keep it that way. Tests call wimlib only through `WIMLib` (`CWIMLib` is imported for the `WIMLIB_ERR_*` constants).
- **`-fno-modules`** in `Package.swift` is a workaround for Mach's `thread_create()` colliding with wimlib's when clang modules are on. Removing it breaks `wim.c`.
- **`-fvisibility=hidden`** is what keeps wimlib's internal symbols out of the global namespace of the final link, where they could collide with libntfs-3g. Check with `nm -gU` after changing flags.
- **Strings returned by wimlib** (`wimlib_get_image_property`) are only valid until the next wimlib call. Copy them at once.
- **`extract` directory semantics.** With `NO_PRESERVE_DIR_STRUCTURE`, a directory path lands in the target as a subdirectory (`/Windows/Boot/EFI_EX` → `target/EFI_EX/...`), not flattened. SnakeStick relies on this, as Rufus does.

## Conventions

- Swift 6.4 tools, `.enableUpcomingFeature("ApproachableConcurrency")` on every target. Zero package dependencies.
- New files start with `// SPDX-License-Identifier: LGPL-2.1-or-later` (C: `/* ... */`).
- Public types use the `WIM` prefix. No C type appears in the public API (`internal import CWIMLib`).
- `WIMFile` is non-`Sendable`; `WIMImage` is a `Sendable` value copied out of the file.
- The README SYNOPSIS is exercised by `ReadmeTests.readmeSynopsis`, with scratch paths. Change both together.
- Comments, commit messages and `README.md`/`CLAUDE.md` are in English, in a neutral tone. `Prompts/` documents and reports are in Korean.

## Git

The repository root (`SnakeStick/`) is the git repository, and other sessions work in other directories of it at the same time.

- Stage and commit with explicit paths only: `git add -- WIMLib` and `git commit -m "..." -- WIMLib` (add `.gitmodules` only when the submodule entry changes).
- Never use `git add -A`, `git add .`, `git commit -a`, `git stash`, or `git reset` without a path.
- Do not touch `slopdisk/`, `NTFS3G/` or the root; problems found there go into the report.
- Commit titles are short English imperatives. No co-author trailers.
