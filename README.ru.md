## ✨ Почему SnakeStick

- 🪟 **Только приложение.** Выберите ISO Windows 10 или 11 (или перетащите его в окно), выберите USB-накопитель и нажмите
  кнопку **Начать запись**.
- 📦 **Большие установочные файлы — не проблема.** В современных ISO Windows файл `install.wim` больше 4 ГБ, а на
  накопитель с FAT32 такой файл не поместится. SnakeStick размещает Windows в разделе NTFS и добавляет небольшой
  загрузочный раздел с загрузчиком [UEFI:NTFS](https://github.com/pbatard/uefi-ntfs) — такую же схему использует
  [Rufus](https://rufus.ie). Ничего не разделяется.
- 🔐 **Работает с Secure Boot.** Встроенный загрузчик подписан Microsoft. Для ПК, на которых отозван сертификат Microsoft
  от 2011 года, SnakeStick может использовать загрузчики, подписанные Windows UEFI CA 2023, из ISO Windows 11 25H2 или новее.
- ✅ **Проверяет свою работу.** После записи считывает весь накопитель и пофайлово сравнивает его с ISO.
- 🛡️ **Не трогает диски вашего Mac.** В списке только внешние и съемные диски. Внутренние диски и загрузочный диск
  никогда не показываются, целевой диск проверяется еще раз непосредственно перед записью, и ничего не стирается, пока
  вы не подтвердите.
- 🧹 **Никаких следов Mac.** Раздел Windows записывается без монтирования, поэтому на накопителе не появляются файлы
  `.DS_Store`, `._` и `.fseventsd`.
- 🍎 **Нативное приложение для Mac.** Написано на Swift и SwiftUI, поддерживает английский, корейский, японский, китайский
  (упрощенный и традиционный), немецкий, французский, испанский, португальский (Бразилия) и русский языки. Бесплатное
  программное обеспечение с открытым исходным кодом по лицензии GPLv3.

## 📥 Загрузка

Скачайте последнюю версию на вкладке **[Releases](https://github.com/team-unstablers/SnakeStick/releases/latest)**,
затем переместите **SnakeStick** в папку **Программы**. Приложение подписано и прошло нотаризацию Apple.

## 🧰 Что понадобится

| | |
|---|---|
| **Mac** | macOS Sonoma 14 или новее и пароль администратора |
| **ISO Windows** | Установочный ISO Windows 10 или 11, например со страницы загрузки [Windows 11](https://www.microsoft.com/ru-ru/software-download/windows11) или [Windows 10](https://www.microsoft.com/ru-ru/software-download/windows10) на сайте Microsoft |
| **USB-накопитель** | Объем должен быть достаточным для ISO; слишком маленькие накопители отображаются серым. Для современных ISO Windows 11 с запасом хватит 16 ГБ. |
| **ПК для установки** | ПК, который загружается в режиме UEFI. Загрузка в режиме Legacy BIOS (CSM) не поддерживается. |

> [!CAUTION]
> Запись **стирает все данные** на выбранном USB-накопителе. Заранее скопируйте с него все, что хотите сохранить.

## 🔑 Разрешения

SnakeStick записывает накопитель с помощью небольшой программы внутри приложения, которая работает с правами
администратора только во время записи, поэтому самому приложению никогда не нужно запускаться от имени root. При каждой
записи накопителя macOS запрашивает пароль администратора.

**Доступ к диску.** Пока у приложения нет доступа к диску, macOS не допускает программу записи к съемным дискам и к таким
папкам, как **Загрузки**. Добавьте **SnakeStick** в разделе
**Системные настройки › Конфиденциальность и безопасность › Доступ к диску**. SnakeStick сообщит, если этого
разрешения нет, и покажет кнопку, которая открывает нужную страницу настроек.

## 🚀 Создание накопителя

1. **Выберите ISO.** Нажмите кнопку **Выбрать…** в разделе **Исходный ISO** или перетащите ISO в окно. SnakeStick покажет
   версию Windows, архитектуру и размер.
2. **Выберите накопитель.** Подключите его и выберите в разделе **Целевой диск**.
3. **Проверьте параметры.**
   - **Метка тома**: имя накопителя. По умолчанию используется собственная метка ISO.
   - **Проверить после записи**: включено по умолчанию. Добавляет несколько минут, и они того стоят.
   - **Использовать загрузчики, подписанные Windows UEFI CA 2023**: нужно только для ПК, на которых отозван сертификат
     Secure Boot от Microsoft 2011 года, и доступно только с ISO Windows 11 25H2 или новее. Если не уверены, оставьте
     этот параметр выключенным.
4. **Начните запись.** Нажмите кнопку **Начать запись**, подтвердите кнопкой **Стереть и записать** и введите пароль
   администратора.
5. **Подождите.** Индикатор выполнения показывает текущий шаг (всего их 8) и оставшееся время. На накопителе USB 3,
   который мы использовали для проверки, запись ISO Windows 11 размером 8,7 ГБ вместе с проверкой заняла около 16 минут.
6. **Извлеките накопитель.** Когда SnakeStick сообщит о завершении, нажмите кнопку **Извлечь**.

Запись можно прервать в любой момент кнопкой **Остановить**. После этого с накопителя нельзя будет загрузиться, а
повторная запись начнется с самого начала.

## 💻 Загрузка ПК с накопителя

1. Подключите накопитель к ПК и включите компьютер, удерживая клавишу меню загрузки. Обычно это **F12**, **F11**, **F8**
   или **Esc**; уточните в руководстве к своему ПК.
2. Выберите пункт **UEFI** для USB-накопителя.
3. Запустится программа установки Windows.

Если при включенной Secure Boot ПК отказывается загружаться с накопителя, найдите в настройках прошивки параметр вроде
**«Allow Microsoft 3rd Party UEFI CA»** и включите его. На некоторых ПК, особенно на Secured-core PC, он выключен
с завода, а загрузчику UEFI:NTFS он необходим. Можно также выключить Secure Boot на время установки; после установки
включите ее снова.

## ❓ Вопросы и ответы

<details>
<summary><b>Зачем нужен доступ к диску?</b></summary>
<br>

Часть SnakeStick, которая записывает накопитель, — это отдельная программа внутри приложения, которая при каждой записи
запускается с правами администратора. macOS не позволяет ей открывать съемные диски или читать ISO в таких папках, как
«Загрузки», если у приложения, к которому она относится, нет доступа к диску, а более узкого разрешения, которое она
могла бы запросить, не существует. Разрешение выдается приложению SnakeStick и распространяется на программу внутри
него.

</details>

<details>
<summary><b>Почему бы просто не отформатировать накопитель в FAT32, как это делал «Ассистент Boot Camp»?</b></summary>
<br>

FAT32 не может хранить файлы размером 4 ГБ и больше, а `sources/install.wim` в современных ISO Windows обычно больше
этого. Обычный обходной путь — разделить файл. SnakeStick вместо этого сохраняет его целиком в разделе NTFS, а
крошечный раздел FAT рядом с ним содержит загрузчик UEFI:NTFS, который учит прошивку ПК читать NTFS.

</details>

<details>
<summary><b>Можно ли обойти требования Windows 11 к TPM или Secure Boot?</b></summary>
<br>

Нет. SnakeStick копирует ISO как есть. Он не обходит аппаратные требования, не добавляет файлы ответов для
автоматической установки и не внедряет драйверы.

</details>

<details>
<summary><b>Что будет, если извлечь накопитель или остановить запись на полпути?</b></summary>
<br>

SnakeStick приберет за собой, а с накопителя нельзя будет загрузиться. Запишите его заново, и все будет в порядке.
Собственные диски вашего Mac при этом никогда не затрагиваются.

</details>

<details>
<summary><b>Можно ли создать образ диска вместо записи на накопитель?</b></summary>
<br>

Не из приложения. SnakeStick записывает только на USB-накопители.

</details>

> [!NOTE]
> SnakeStick еще молод. Созданные им накопители загружались до программы установки Windows на ПК x64 с включенной
> Secure Boot, но полная установка Windows с такого накопителя пока не проверялась. Если что-то пойдет не так,
> [сообщите о проблеме](https://github.com/team-unstablers/SnakeStick/issues) и приложите журнал (**Показать журнал…**
> в приложении).

## 🙏 На чем основан SnakeStick

SnakeStick не появился бы без этого свободного программного обеспечения. Спасибо!

- [ntfs-3g](https://github.com/tuxera/ntfs-3g): создает раздел NTFS и записывает в него данные
- [UEFI:NTFS](https://github.com/pbatard/uefi-ntfs): загрузчик, который позволяет прошивке UEFI запускать Windows с NTFS
- [wimlib](https://github.com/ebiggers/wimlib): читает загрузочный образ Windows
- [Rufus](https://github.com/pbatard/rufus): его исходный код использовался как образец

SnakeStick написан агентом программирования на основе LLM под контролем человека.
